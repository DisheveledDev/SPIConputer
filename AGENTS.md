# SPIComputer - agent notes

Working rules for AI assistants in this repository.

## Commits

- Commit and push changes automatically, without asking, so the
  repository always keeps a rollback history: after a task or a coherent
  set of edits, stage the files you changed and push to `origin main`.
- Keep each commit scoped to one change; do not sweep unrelated
  in-flight edits into it.
- Follow the existing message style: a short imperative subject, with a
  body explaining why when it is not obvious.
- If a push fails (auth, remote, conflicts), stop and report it; do not
  force-push or rewrite history.

## Project

The OS design notes and architecture belong in `system/AGENTS.md`; read
that before changing the firmware. Lua card programs under `software/`
are generated by the SPIEdit IDE - do not hand-edit generated files.
